    版本更新记录

    Unreleased¶

    • 接入外部信息补充器（Collector/Bridge），爬虫 API 默认使用 127.0.0.1:56790；DarkEye 主程序内部服务仍使用 127.0.0.1:56789。
    • 设置页支持配置、启动和探测外部信息补充器，并可选择随 DarkEye 自动启动已配置的可执行文件。
    • 外部信息补充器的源码和构建脚本不在本仓库中，相关启动与打包需要在对应项目中完成。
