# 浏览器式停靠工作区

桌面主窗口采用 MyADS WorkspaceWidget，按 Ctrl/Cmd+O 搜索实体，按 Ctrl/Cmd+P 打开命令面板，按 Ctrl/Cmd+, 直达设置。
原来的 Sidebar / mainPages 单页切换容器已移除。

## 使用

以下为默认快捷键，Ctrl/Cmd 表示 Windows 和 Linux 使用 Ctrl，macOS 使用 Cmd。工作区快捷键可在「设置」→「快捷键」中修改。

- 在「设置」→「导航栏」中可以选择左侧导航栏显示的入口，也可以关闭整条导航栏。各入口默认显示，修改即时生效并自动保存。
- 在「设置」→「边栏」中可以分别设置左右边栏的展开／收起按钮，以及焦点离开时是否自动收起。已有的自动收起设置会作为两侧的初始值。
- Ctrl/Cmd+O 支持按姓名、别名、番号或标题搜索，也能查找标签、片商、厂牌、系列和导演。选择男优、片商、厂牌、系列或导演时，打开 DVD 浏览并应用对应筛选。搜索框为空时显示最近打开的最多 9 个实体。“查看全部搜索结果”会打开独立搜索标签。
- Ctrl/Cmd+P 无需输入即可浏览所有可用的页面和命令。输入「平铺浏览」「统计」或「标签管理」等名称可直接筛选。也可用「商店」「通知」「软删除」等旧名称找到新入口。
- 输入「批量」可查找维护命令。选择命令后在当前工作区执行，重新打开命令面板可查看任务状态。
- 在命令面板搜索「恢复预设工作区布局」可选「默认」或「纯浏览」。默认布局的中间上方是 DVD 浏览、平铺浏览、女演员和男演员共用的标签组，下方是作品时间轴。纯浏览的中间只有 DVD 浏览，左栏是作品过滤器，右栏上方是局部关系图，下方是跟随切换的女演员详情。切换时会关闭预设之外的标签，未保存的编辑可保存、放弃或取消切换。
- 方向键选择结果，Enter 确认，Escape 或焦点离开弹窗时关闭。
- 作品详情在 DVD 浏览中定位并展开。从作品详情打开剧照时，标签标题显示为「番号 · 剧照」。人物独立页、编辑器和剧照按实体 ID 打开。
- 在命令面板打开「作品过滤器」标签页。筛选条件和排序同时应用到平铺浏览和 DVD 浏览。
- 拖动标签到内容区边缘分屏，拖到另一个标签组中合并；右键标签提供批量关闭及移动操作。
- 按 Ctrl/Cmd+Alt+→ 或 Ctrl/Cmd+Alt+← 按工作区布局顺序循环切换到下一个或上一个窗格。macOS 上的 Alt 键为 Option。
- Ctrl/Cmd+W 关闭当前标签。当前窗格内循环切换标签页时，macOS 使用 `Cmd+Shift+]` 和 `Cmd+Shift+[`，Windows 和 Linux 使用 `Ctrl+Tab` 和 `Ctrl+Shift+Tab`，分别切到下一个和上一个标签页。
- 没有已保存的布局时，启动直接打开默认工作区。退出时保存布局、标签顺序和活动页到配置目录 workspace-v2.json，下次启动恢复。关闭最后一个标签后，空工作区会提示两个快捷键。
- 标签管理、片商管理、厂牌管理、系列管理、资料汇总、个人记录、批量移入回收站和回收站均可通过 Ctrl/Cmd+P 打开。
- 标签切换与拖动保留页面的筛选和滚动状态。
- 女演员列表成为活动页时，局部关系图显示符合列表筛选的女演员及其关联作品，并随筛选更新。
- 在 Ctrl/Cmd+P 中打开「作品时间轴」，可拖动标签分屏。焦点切到女演员详情或编辑页时，时间轴显示该演员参与的作品。焦点切到平铺浏览或 DVD 浏览时，时间轴随筛选显示完整结果。操作时间轴时会保留最近关联的页面，点击作品标记可在 DVD 浏览打开作品。
- 「女演员详情（跟随切换）」复用同一个详情标签。「女演员详情（独立页）」可把指定演员单独打开。
- 人物和作品编辑页关闭时支持保存、放弃和取消；应用退出也会先执行关闭检查。

## 路由与生命周期

`MainWindow::ensurePage` 按路由缓存 QPointer；`navigateTo` 将页面放入活动窗格或定位已有内容。
路由形式示例：

| 路由 | 页面 |
| --- | --- |
| home / mutiwork / shelf | 作品展厅、平铺浏览和 DVD 浏览 |
| actress / actor | 女演员和男演员 |
| chart | 统计图表 |
| library_overview / top_actresses / record_heatmap | 库藏概览、最喜欢的女优、个人记录热力图，均可独立打开和停靠 |
| inbox / av | 采集任务和暗黑界知识库 |
| actress_detail/ID | 独立女优详情 |
| actor_works/ID | 在 DVD 浏览筛选男优的作品 |
| work_detail/ID / work_edit/ID | 在 3D 书架定位作品 / 独立作品编辑 |
| modify_actress/ID / modify_actor/ID | 独立人物编辑 |
| graph / local_graph | 全局关系图和随焦点更新的局部关系图 |
| timeline / work_filters | 作品时间轴和作品过滤器 |
| fanart_work/ID | 作品剧照 |
| tag/ID | 标签作品视图 |
| maker/ID / label/ID / series/ID / director/ENCODED_NAME | 在 DVD 浏览筛选作品 |
| search/ENCODED_QUERY | 完整搜索结果，支持继续加载 |
| manage_* | 拆分后的管理功能 |

PaneWidget::contentClosed 只在实际关闭成功后发出，经 WorkspaceWidget 转发。
主窗口立即移除缓存，避免在 deleteLater 执行前重新打开并复用待销毁页面。
移动、分屏、布局恢复不会发出此关闭信号。

持久化恢复使用实体 ID，不保存编辑器未提交的表单。列表筛选状态随打开的页面实例保留；重启恢复布局时，列表重新加载默认筛选。
