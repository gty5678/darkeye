# Cover Maker

独立 Qt Widgets 封套合成库，仅依赖 Qt Widgets，不依赖数据库、主程序 UI 或 AI 服务。链接目标：`darkeye::cover_maker`。

## 完整封套

- `SleeveDocument`：封底、书脊、封面三个独立的 `CoverDocument`；分别设置三个宽度和共同高度。
- `SleeveEditor`：三个编辑页、实时合成预览、尺寸输入、完整 PNG 导出和应用信号。
- `paintSleeve` / `renderSleeve`：严格按 **封底 → 书脊 → 封面** 横向排列，没有间隙或辅助线。
- `saveSleeve`：通过 `QSaveFile` 原子写入完整 PNG。
- `applyRequested(QImage)`：交付完整封套，由宿主保存、更新条目、清理缩略图缓存并报告结果。

```cpp
#include <cover_maker/SleeveEditor.h>
auto *editor = new darkeye::cover_maker::SleeveEditor(parent);
// connect(editor, &SleeveEditor::applyRequested, host, ...);
```

三个区域各自保留图片、布局、裁切位置、缩放、底色和独立文字图层。可添加 / 删除多段文字，编辑多行内容，点击画布中的文字后拖动位置；右侧可选择系统字体、成品像素字号（6–1000 px）、加粗、文字颜色和 0° / 90° / 180° / 270° 方向。重叠文字优先选中后添加的一层，也可通过图层下拉框选取。书脊新文字默认正立竖排；可不放图片，仅使用底色和文字。

`TextLayer` 以区域内归一化中心点保存位置，字号以输出像素保存。预览、命中测试、选择框和导出共享字体度量及旋转变换。文字超出区域时按区域边缘裁切，不会绘制到相邻封套区域；选择框不导出。修改尺寸会保留图层内容、相对位置和字号。每个区域仍支持单图、上下双图或主图加小图。

## 默认比例来源

读取当前 `libs/dvd/dvd.glb` 中 `back`、`spine`、`front` 的 `pic` 材质 `TEXCOORD_0`，书脊两侧的 U 分界约为 **0.4766346 / 0.5252864**。完整模型直接采样整张封套贴图，没有额外的 CPU 裁切。

以现有 `resources/maps/0.png` 的 **800×540** 画布为基础放大四倍，默认输出 **3200×2160**；将 U 分界取整到像素，得到宽度 **1525 / 156 / 1519**。宽度包含模型在整张贴图两端未完全采样的少量边缘，保留现有贴图坐标约定。该比例是基于当前模型的固定预设；替换模型 UV 后应重新核对。界面提供恢复模型比例按钮，也可手动输入其他尺寸。

## 单区域与限制

`CoverEditor` / `CoverDocument` 可单独复用；`renderCover` / `paintCover` 共享预览及导出绘制逻辑。编辑器应用 EXIF 方向，大图缩至最长边 4096 像素。输出总宽和高度各最多 8192 像素。

旧文档的标题和编号在进入编辑器时转换为可移动图层；删除后不会重新生成。多行文字按显式换行绘制，不自动换行或缩小。切换布局保留未使用的第二张图片。完整封套空白图片位置显示底色，不会导出占位提示。调用方应在 GUI 线程使用编辑器并保持有效的 `QApplication`。

当前不包含超分辨率、撤销重做、工程文件持久化或打印出血设置。

## 自由图片图层

`ImageLayer` 以 `frame` 保存区域内的相对目标位置和大小，以 `crop` 保存原图中的相对保留范围。图片原始像素不被裁剪覆盖，`imageLayerRect` / `imageLayerSource` 为编辑器和渲染器提供统一坐标。旧固定槽位进入编辑器时自动迁移为图片图层，保留原先可见构图；删除后不会重新出现。

- “添加图片…”可多选文件，每张成为独立图层，初始按原图比例适应画布。
- 点击图片拖动位置；滚轮、放大 / 缩小按钮、四个角点均可等比缩放。缩小后可露出底色。
- “裁剪当前图片…”打开原图预览，拖动框选保留范围，确认后以裁剪后的比例显示；取消不改变构图。
- “完整原图适应画布”恢复完整原图并重新居中。
- 图片图层下拉框可选取被遮挡的图片；上移 / 下移一层控制图片之间的遮挡。文字统一绘制在图片之上。
- 快速布局作用于前两张图片，重新按模板设置裁剪及位置；其余图片保留。选择“自由摆放”不重置现有构图。
- 超出封套区域的部分仅在显示和导出时裁切，不会覆盖相邻区域。修改封套尺寸后保留图片中心、相对宽度和裁剪，按新尺寸调整高度以维持图片比例。

## 横排与竖排

每个文字图层可独立选择“横排”或“竖排（文字正立）”。竖排按 Unicode 字素簇从上到下绘制，组合字符及 emoji 不拆开；换行会从右向左开始新列。横排保留从左到右和多行显示。文字的选择框、拖动命中范围与导出均使用同一排列度量。

切换排列时保留内容、位置、字体和字号，并恢复为 0° 旋转；随后仍可单独设置旋转角度。书脊新添加的文字默认正立竖排，旧有旋转文字保持原样，选择竖排即可改为正立排列。当前为逐字正立排版，未实现专门的竖排标点替换或连续拉丁词组侧排。
