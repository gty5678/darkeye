# Cover Maker

独立 Qt Widgets 封套合成库，链接目标 `darkeye::cover_maker`，不依赖数据库、主程序 UI 或 AI 服务。

## 一体画布

`SleeveEditor` 使用一张完整封套画布，所有图片和文字共用坐标系，可以跨封底、书脊、封面的参考线自由摆放。新建时为空白画布，由用户导入素材自由布置；没有快速布局、分区编辑页或独立预览。两条参考线及区域名称仅供编辑参考，不会导出，也不限制图层移动或裁切。

`SleeveDocument::composition` 保存完整 `CoverDocument`，`unified=true` 时由 `paintSleeve` / `renderSleeve` 直接绘制；`saveSleeve` 通过 `QSaveFile` 原子保存 PNG。`applyRequested(QImage)` 交付完整封套，由宿主负责保存并更新条目。

```cpp
#include <cover_maker/SleeveEditor.h>
auto *editor = new darkeye::cover_maker::SleeveEditor(parent);
// connect(editor, &SleeveEditor::applyRequested, host, ...);
```

旧分区文档仍可读取：`unifiedComposition` 将三个区域的素材和文字映射到整张画布，进入编辑器后统一编辑。旧标题、编号和固定图片槽位自动成为独立图层，删除后不会重新出现。

## 参考范围与默认比例

画布左至右为封底、书脊、封面。三个宽度和共同高度统一在顶部“画布设置…”弹窗输入像素数；弹窗内显示合成尺寸、宽度比例及恢复默认比例按钮。确认后参考线更新，取消不修改文档；总宽超限时无法确认。主界面不展示尺寸输入与比例明细。仅调整参考线位置且总尺寸不变时，不改变现有构图。

当前 `libs/dvd/dvd.glb` 的 `pic` 材质 UV 分界约为 **0.4766346 / 0.5252864**。以 `resources/maps/0.png` 的 **800×540** 为基础放大四倍，默认输出 **3200×2160**；分界取整得到宽度 **1525 / 156 / 1519**，包含原模型两端的少量贴图边缘。替换模型 UV 后应重新核对预设。

## 图片

- 多选文件导入为独立图层，点击拖动，通过四角控制点等比缩放图片。滚轮以鼠标位置为中心缩放画布视图，按住鼠标中键拖动可平移画布视图，不改变图片尺寸或导出结果。
- 图片属性提供“原图适应左半封面”和“原图适应右半封面”：恢复完整原图，按目标区域宽度等比缩放并垂直居中。封套模式按封底、封面参考线划定区域，避开书脊；普通画布按左右各半处理。支持撤销。
- 通过统一图层列表选择遮挡对象，上移 / 下移调整图片与文字的共同遮挡顺序。
- 选中图片后点击“画布内裁剪”，直接拖动黄框的八个边角手柄调整范围，拖动框内移动取景范围；鼠标移动时主画布和导出数据立即更新。被裁掉的原图以淡色辅助显示，不导出。
- 点击“完成裁剪”或 Enter 确认，点击“取消裁剪”或 Esc 恢复进入本次裁剪前的范围和位置。原图保留，可再次向外扩展裁剪框；完整原图适应画布可恢复完整原图，按画布宽度等比铺满并居中，高度可超出画布。
- `ImageLayer::frame` 为完整画布内的相对目标位置与大小，`crop` 为原图中的相对保留范围。
- 图层仅在整张画布外缘被裁切，不在封底 / 书脊 / 封面分界处裁切。

## 文字

可添加多段文字、自由拖动、修改系统字体、字号（成品像素 6–1000 px）、颜色、加粗和旋转。图片与文字共用 z 顺序，画布优先选中最上方可见且未锁定的对象，也可从统一图层列表选择。

每层可选择横排或正立竖排；竖排按 Unicode 字素簇从上向下排列，回车从右向左开始新列。组合字符与 emoji 不拆开。切换排列保留位置、内容、字体和字号，并将旋转恢复为 0°，之后可独立设置旋转。位置以整张画布归一化中心点保存；选框、命中测试与导出共用度量。文字按显式换行排列，不自动缩小或换行。当前不包含专门的竖排标点替换或拉丁词组侧排。

## 限制

`CoverEditor` / `CoverDocument` 亦可单独复用，`setGuideLines` 设置仅编辑时显示的参考线。需要 GUI 线程与有效的 `QApplication`。加载图片应用 EXIF 方向，最长边缩至 4096 像素；输出总宽和高各最多 8192 像素。

当前不包含超分辨率、工程文件持久化或打印出血设置。

画布左上方提供两个独立的图标按钮：添加图片、添加文字，悬停可查看名称。右侧为上下文属性栏：选中图片时显示图片属性，选中文字时显示文字属性；未选中时显示操作提示，同一时间只显示一类对象的属性。

顶部“显示参考线与区域名”开关默认开启，同时控制两条辅助线与封底、书脊、封面的文字标签。该开关仅改变编辑视图，不影响画布内容或导出。

选中竖排文字时，文字属性显示“上下字间距”：正数加大上下间隔，负数收紧，0 为默认间隔，单位为导出像素。每个文字图层独立保存，切换横排时隐藏此项并保留数值，预览、选择框和导出同步更新。

竖排默认按一倍字号的中心距离紧凑排列，不再叠加字体的横排行距；上下字间距为 0 时使用此默认距离，正负值可继续微调。


## 编辑历史、图层与对齐

- 顶部撤销 / 重做按钮及系统快捷键（macOS Cmd+Z / Cmd+Shift+Z）恢复文档与选择状态，保留最多 100 步。一次拖动、缩放手柄操作或完成裁剪为一步；连续输入同一属性在短时间内合并。取消裁剪不加入历史。添加、删除、复制、排序、显隐、锁定、文字属性、底色及画布尺寸均支持撤销；重新加载外部文档会清空历史。
- 右侧统一图层列表从上到下显示最终遮挡顺序，图片和文字可互相覆盖；复选框控制显隐与锁定。锁定后不可拖动、缩放、裁剪、对齐、删除或修改属性，仍能从列表选择并解锁或复制。隐藏影响最终导出。
- 对齐可选整张画布、封底、书脊或封面参考范围，再选择左右 / 上下 / 水平与垂直居中。旋转文字按变换后的包围框对齐。
- 拖动吸附默认开启，按屏幕约 6 像素的容差对齐到画布边缘、中心、分区参考线、分区中心和其他可见对象的边缘 / 中心。拖动时显示临时吸附线，按住 Alt 可暂时关闭；不改变导出。
- 文字支持描边开关、颜色和宽度；偏移阴影开关、颜色与 X/Y 偏移；底色开关和含透明度的颜色。阴影为清晰偏移效果，不包含模糊。横排、竖排及旋转共用同一导出绘制逻辑。


## 快速制作界面

默认只显示常用属性和删除；完整图层列表、复制 / 锁定 / 排序、详细对齐及文字特效放在默认折叠的“更多”里。常用文字属性保留字体、字号、加粗、旋转、颜色、横竖排和字间距；描边 / 阴影 / 底色参数放在“更多”里按需展开。吸附保持默认开启，Alt 暂停。

支持把本地图片文件直接拖到画布，按原图比例适应并放到落点附近，多图导入可一次撤销。添加文字立即打开画布内输入框，双击已有文字可继续编辑；Enter 完成，Shift+Enter 换行。普通属性栏内容框仍可编辑同一段文字。

`SleeveEditor::setApplyVisible(false)` 允许独立工具隐藏应用入口；实际条目宿主可保留按钮并连接 `applyRequested`。Demo 默认隐藏应用，只保留导出。

文字边界使用与实际绘制相同的字形轮廓计算，去除字宽估算、行高留白和额外补边。描边、阴影和文字底色计入可见边界；旋转后的对齐与吸附直接计算变换后的轮廓范围，选框同样使用该范围。详细对齐按实际可见内容对齐，而非字体行框。

画布上方常驻“吸附”开关，默认开启，可随时关闭；按住 Alt 仍可临时暂停吸附。

横排文字属性提供“左右字间距”：0 为字体原始间距，正数拉开、负数收紧，单位为导出像素。横排与竖排间距独立保存，切换排列后保留设置。字形绘制、选框、居中、吸附和导出共用调整后的字体度量。

文字旋转为常用属性中的角度输入框，支持 -360° 至 360° 的任意角度（两位小数），正数顺时针、负数逆时针，输入实时更新，并支持撤销 / 重做。

## HTTP 超分

`UpscaleClient` 异步上传 `multipart/form-data` 至配置的 `/v1/upscale`：仅一个文件字段 `image`，服务端固定返回原图宽高各 2 倍的 PNG，可带 Bearer token，返回定尺寸 PNG。仅接受 HTTPS 或回环 HTTP，校验服务证书，禁止自动重定向，支持取消、请求超时及响应尺寸限制。`DARKEYE_SR_CA_FILE` 可增加自建 CA。

编辑器图片属性的“高清增强…”调用客户端；“更多 → 超分服务设置…”或 `DARKEYE_SR_URL` / `DARKEYE_SR_TOKEN` 配置地址与令牌。结果保留图层 frame/crop，作为一步撤销；处理中若文档有变化则丢弃结果。独立服务见同级 SRkit 项目，模型与原生 Vulkan 运行库不进入此库。
